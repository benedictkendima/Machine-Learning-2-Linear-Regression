# Machine Learning 2 - Linear Regression

This project explores the implementation of Linear Regression for predicting continuous values from numerical data.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

### Activities
- Data preprocessing
- Feature selection
- Model training and testing
- Prediction
- Model evaluation

### Objective
To gain practical experience in building and evaluating Linear Regression models.
